Willkommen bei der IT-Trainingsplattform

Eine interaktive Übungsumgebung für IT-Grundlagen – von Hardware und Windows über Netzwerke und Security bis Cloud. Alles läuft komplett in deinem Browser – es gibt keinen echten Server und keine echte Datenbank im Hintergrund. Dein Fortschritt wird nur lokal auf diesem Gerät gespeichert (localStorage), es ist kein Login nötig.

Hinweis Diese Plattform ist eine reine Lernsimulation. Insbesondere das SQL-Injection-Modul arbeitet ausschliesslich gegen eine im Browser hartcodierte Fake-Datenquelle – es gibt keine echte Datenbank, keinen echten Server und keine echte Codeausführung von Eingaben.
